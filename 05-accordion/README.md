# アコーディオン（FAQ）

## 何を作ったか

質問をクリックすると答えが開閉するFAQ。1つ開くと他は自動で閉じる（排他制御）。

## なぜ・どこで使うか

FAQ・サービス紹介・商品説明などで頻出。情報を畳んでおいて、必要な項目だけ開いて読ませたいときに使う。

## 実装のポイント

- 開閉そのものは `<details>`/`<summary>` の標準機能。クリック開閉・キーボード操作・スクリーンリーダー対応がHTMLだけで付いてくるので、JSなしでも動く。
- 「1つ開くと他が閉じる」は、まず `<details>` に同じ `name="faq"` を付けるとHTMLだけで実現できる（比較的新しい機能）。古いブラウザでも動くよう、同じ動きをJSでも書いた（保険＋練習）。

### 今日いちばん理解に時間をかけた所：JSの排他制御

JSはループが2重になっている。役割が違うのがポイントだった。

- **外側 `items.forEach((item) => {...})`** … 各 `<details>` に「開閉されたら〜」という設定（`toggle` イベント）を1個ずつ取り付ける初期設定。最初に1回だけ走る。
- **内側 `items.forEach((other) => {...})`** … どれかが開かれた瞬間に走る後始末。全項目をもう一度見て、開いた本人以外を閉じる。

- `toggle` は `<details>` が開いた／閉じたときに発火するイベント。`if (item.open)` で「開いたときだけ」処理した（閉じたときは何もしなくていい）。
- 内側の `if (other !== item)` が肝。これが無いと開いた本人まで `open = false` で閉じてしまい、一瞬で全部閉じて開けなくなる。「本人（item）はスキップして、それ以外（other）だけ閉じる」ことで「開いた1個は残す／他は閉じる」が成立する。
- この「自分以外をリセットする」流れは、Day2のスクロールスパイ・Day3のカテゴリボタンと同じパターン。
