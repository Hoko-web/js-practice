# 料金プラン表（月額／年額トグル）

## 何を作ったか

3プランを横並びにした料金表。真ん中を「おすすめ」で強調し、上のトグルで月額⇄年額の価格を切り替えられる。

## なぜ・どこで使うか

LP・SaaS・サービスサイトで超頻出。プラン比較の見せ方（カード設計・強弱）と、価格の出し分けは実務でよく作る。トグルUIや `is-active` の切替は他の切替系（タブ・フィルター）にも流用できる。

## 実装のポイント

- **カードの等高揃え**：CSS Grid の `align-items: stretch`（初期値）で、全カードを一番高いカードの高さに自動で揃える。`min-height` の決め打ちが要らない。
- **おすすめの強調**：`--recommend` 修飾クラス＋バッジを `position: absolute` ＋ `transform: translate(-50%, -50%)` で枠線の上にまたがせる。PCでは `transform: scale(1.05)` で少し大きく。
- **ボタンの下端揃え**：カードを `flex-direction: column` にして、ボタンに `margin-top: auto`。特徴の数が違ってもボタンが常に最下部に揃う。
- **価格の出し分け**：金額に `data-monthly` / `data-yearly` の2値を持たせ、押したトグルの `data-term`（"monthly"/"yearly"）を鍵にして `price.dataset[term]` で読み分け。`[ ]`（ブラケット記法）が「変数の中身をプロパティ名にする」ので、`if` 分岐なしで切り替わる。
- **切替UIの定番**：`is-active` を「一旦全ボタンから外す → 押したボタンに付ける」。1つだけ選択のUIの型（タブと同じ）。
- **a11y**：トグルは `<button type="button">`、CTAは `<a>`、見出しは h1→h2。
