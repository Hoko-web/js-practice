# スクロールでフェードイン

## 何を作ったか

スクロールして要素が画面に入ると、下からふわっと浮かんで表示される演出。一度表示したら、上に戻っても消えない。AOSなどのライブラリを使わず、IntersectionObserver + CSS で自作した。

## なぜ・どこで使うか

今どきのLP・コーポレートサイトでほぼ必ず使う表示演出。AOSで実現することが多いが、中身は同じ仕組みなので、自作できると軽量＆自由。

## 実装のポイント

- 役割分担：「いつ出すか」はJS、「どう出すか」はCSS。
- CSSの初期状態で `opacity: 0` ＋ `transform: translateY(30px)` にして隠しておき、`transition` を付けておく。JSが `is-show` を付けると `opacity: 1` / `translateY(0)` に戻り、その変化が transition でふわっと動く。
- JSは `IntersectionObserver` で各要素を監視し、画面に入ったら（`isIntersecting`）`is-show` を付ける。
- `observer.unobserve(entry.target)` で、一度表示した要素は監視を外す（＝もう発火させない）。理由は2つ：表示済みを監視し続けるのは無駄／監視したままだと上に戻ったとき再アニメしかねない。「一度きり」を保証する。
- `rootMargin: "0px 0px -10% 0px"` で、画面の下端ぴったりではなく少し入ってから発火させ、自然な見え方にした。
- `@media (prefers-reduced-motion: reduce)` でアニメを抑制（a11y配慮）。

### Day2（スクロールスパイ）との違い

- Day2：中央線に絞って、見える要素に応じてクラスを付けたり外したりし続ける（現在地が動くから）。
- Day6：一度入ったらクラスを付けて `unobserve`。付けっぱなしで二度と外さない（一度出したら戻さないから）。

## AOSとの関係

AOS（Animate On Scroll）も中身は「要素が見えたか監視 → 入ったらクラスを付ける → CSSでアニメ」という同じ仕組み。それをライブラリとして包み `data-aos="fade-up"` で使えるようにしたもの。今回はその正体を自分で書いた。
