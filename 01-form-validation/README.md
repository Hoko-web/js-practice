# フォームバリデーション

## 何を作ったか

お問い合わせフォームの入力チェックを JavaScript で実装。お名前・メール・メッセージの3項目を送信時に検証し、エラーがあれば各欄の下に赤いメッセージを表示する。全項目 OK なら「送信しました！」のアラートを出してフォームをリセットする。

## なぜ・どこで使うか

ほぼ全サイトにあるお問い合わせフォームで必須の機能。送信前に入力ミスをその場で知らせて UX を上げ、空欄や不正な値が運営側に届くのを防ぐ。

## 実装のポイント

- `e.preventDefault()` でデフォルトの動作（送信時のブラウザリロード）を止め、JS で自前のエラー表示を出せるようにした。
- `closest(".form-group")` で「その欄の箱」を特定し、欄ごとにエラーを出し分けた。
- 必須 ／ メール形式（正規表現 `.test()`）／ 文字数（`.length`）の3種類のチェックを実装した。
- エラーがある欄では `isValid = false;` にしてフラグを下げ、最後に `if (isValid)` で判定。`isValid` が true のまま（＝全欄 OK）なら成功アラートを出し、`form.reset()` で入力をリセットした。（`isValid = false` ＝減点する側、`if (isValid)` ＝採点する側、と役割を分けて理解した）
- `.trim()` の役割を調べ、検索フォームなどで「コピペ時の余分な空白を前処理で吸収する」用途にも使われると理解した（前後の空白のみ除去する点も確認）。
- ハマった点：`null` の `.trim()`、`.text` / `.test` の取り違え、変数名の不一致。エラーメッセージ（`Cannot read properties of null` / `is not a function` / `is not defined`）を読んで原因を特定し、自力で修正できた。
