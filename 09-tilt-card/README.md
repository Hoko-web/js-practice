# 3Dチルトカード（マウス追従）

## 何を作ったか

カードにマウスを乗せると、カーソルの位置に合わせてカードが3Dで傾く演出。マウスを動かすと追従して傾き、離すとフワッと平らに戻る。すりガラス風（グラスモーフィズム）のデザインで、複数枚並べても各カードが独立して動く。ライブラリは不使用（バニラJS）。

## なぜ・どこで使うか

商品カード・ポートフォリオカード・採用サイトのメンバー紹介など、“魅せる”カードUIで使う演出。ブランド系・デザイン重視のサイトで映える。
技術的には **「`mousemove` でマウス座標 → 数値計算 → `transform` で反映」** という、追従系インタラクション全般（パララックス・マウスストーカー等）に応用できる汎用パターン。

## 実装のポイント

- **マウスのズレ → 傾き角度への変換**が中心。
  1. `getBoundingClientRect()` でカードの位置・サイズ → 中心座標を出す。
  2. `e.clientX / clientY`（マウス座標）と中心の差＝「中心からのズレ」。`getBoundingClientRect` も `clientX` も同じ画面基準なので引き算できる。
  3. ズレを `÷ (幅 / 2)` で **-1〜1 に正規化**（カードの大きさに依存しない割合にする）。
  4. それに `× 15` で **-15°〜15°** の角度にして `transform: rotateX() rotateY()` で適用。
- **3Dの奥行きは CSS `perspective`**：親（`.container`）に `perspective: 1000px`。これが無いと `rotateX/Y` が「ペラ紙が回る」だけで立体に見えない。値が小さいほど傾きが大げさになる。
- **戻りの質感**：`mouseenter` で `transition` を速く（`0.1s`＝キビキビ追従）、`mouseleave` で遅く（`0.6s`＝ゆっくり戻る）切り替え。追従と戻りで速さを変えると上質に見える。離すときは `transform` を0に戻す。
- **複数対応は `querySelectorAll` + `forEach`**：`querySelector` は最初の1個しか取らないため、複数カードだと1枚目しか動かない。全部取って1枚ずつイベントを付ける。各ハンドラ内の `card` はその回のカードを指すので、独立して動く。
- **デザイン**：`backdrop-filter: blur()` ですりガラス、背景に `radial-gradient` の光のにじみを2枚置いてガラス越しに映えさせる、半透明の `border` でガラスのフチの反射を表現。

## つまづき＆気づき

- **複数あるのに1枚しか動かない → `querySelector` を疑う**。`querySelector`（最初の1個）と `querySelectorAll`（全部）の違い。02・05でやった「forEachで全部に付ける」と同じパターンだった。
- **`background` のカンマ区切りは、1個のタイポで全滅する**。`radial-gradient` を `redial` と打ち間違えたら背景ごと無効化され、白背景＋白文字で画面が真っ白に。「急に背景が消えた」ときはまずスペルを疑う。
- `perspective` を親に置かないと3Dにならない、という親子関係が最初ピンとこなかった。
