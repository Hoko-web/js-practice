# モーダル（dialog）

## 何を作ったか

ボタンを押すと前面にお知らせモーダルが開き、背景が暗くなる。閉じる方法は「閉じるボタン / ESCキー / 背景クリック」の3つ。

## なぜ・どこで使うか

お知らせ・確認ダイアログ・画像拡大・予約フォームなど、Web制作で頻出。前面に小窓を出して操作や情報を集中させたいときに使う。

## 実装のポイント

- `<dialog>` 要素を `showModal()` で開き、`close()` で閉じた。
- `<dialog>` を `showModal()` で開くと、ESCで閉じる・背景を暗くする（`::backdrop`）・後ろのスクロールを止める・フォーカス管理…が標準で付いてくる。過去の課題ではこのうち「背景の暗幕」と「スクロール止め」を自前で書いていたので、標準で済むのは大きいと感じた。
- 背景クリックで閉じる処理は `if (e.target === modal)` で判定。`<dialog>` 全体でクリックを拾うと中身を押しても閉じてしまうため、押された要素が `modal` 自身（＝背景部分）のときだけ閉じるようにした。
- 閉じるトリガーが複数（ボタン / ESC / 背景クリック）あるのは、過去案件のドロワーと同じ考え方。

## 応用・発展メモ

- このモーダルは「画像ライトボックス（サムネをクリックして拡大表示）」の土台にもなる。中身を画像に差し替えるだけで、制作実績ギャラリー・写真サイト・ECの商品画像ズームなどに使える。
- 発展させるなら、サムネに `data-src` で大きい画像のパスを持たせて `<img>` の `src` を差し替える（Day3の dataset の応用）、前へ／次へで複数画像を送る（配列操作の応用）など。
- 拡大画像は `width`/`height` 明示（CLS防止）・`loading="lazy"`・`alt` を忘れない。
