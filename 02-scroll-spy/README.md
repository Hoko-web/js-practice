# スクロールスパイ

## 何を作ったか

縦に長いページをスクロールすると、いま画面中央に見えているセクションに対応する目次リンクが自動でハイライトされる機能。

## なぜ・どこで使うか

縦長LP・コラム記事・ドキュメントのサイドナビで定番。「自分が今どこを読んでいるか」が分かるので回遊しやすくなる（UX向上）。

## 実装のポイント

- `IntersectionObserver` で各セクションを監視。要素が境界をまたいだ瞬間だけ通知が来るので、`scroll` イベントで位置を毎回計算する旧来のやり方より軽い。
- `rootMargin: "-50% 0px -50% 0px"` で判定エリアを「画面中央の線」だけに絞り、現在地を常に1つに定めた（最初は2つ同時に光ったり、間のセクションが飛ばされたりで詰まった）。
- 中央に来たセクションの `id` から `.toc-link[href="#${id}"]` で対応リンクを特定し、全リンクから `is-active` を外してその1つだけに付ける（常に1つだけ光らせる）。
- ハマった点：`rootMargin` を付ける場所を間違えた／`<section>` の `id` に `#` を付けてしまった／`observe()` を呼ばないと「エラーも出ずに無反応」になることを体験した。
