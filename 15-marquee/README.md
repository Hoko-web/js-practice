# スクロール連動マーキー（無限スクロールテキスト）

大きい文字の行が左右交互に無限に流れ、**スクロールするとビュンと加速して、止めると元の速さに戻る**。Awwwards系のブランドサイトでよく見る背景演出。

## 何を作ったか

文字でびっしり埋めた行を何本も並べ、`requestAnimationFrame` で横に無限スクロール。行ごとに流れる向きを左右逆にし、ページのスクロール量を流れる速度に上乗せした。

## なぜ・どこで使うか

ブランドサイト・ポートフォリオの背景や帯（ロゴ列・キャッチコピーの流れる演出）で使う。スクロール連動は"生きてる"動きでリッチさが出る。技術的には **「rAFで毎フレーム動かす＋スクロール量を速度に反映」** という、スクロール演出全般に通じる型。

## 実装のポイント（JS：主役）

- **無限ループのカラクリ**：同じ文字グループを `cloneNode` で2枚並べ、1枚分（`groupWidth`）動いたら `offset += groupWidth` で位置を戻す。2枚が同一なので、戻した瞬間も見た目が変わらず**継ぎ目が見えない**。
  - 戻すのに `offset = 0`（リセット）でなく `+= groupWidth` なのは、**行き過ぎた端数を残して**カクつきを防ぐため。
- **毎フレーム動かす**：`offset += speed * direction` を `requestAnimationFrame` で繰り返し、`row.style.transform = translateX(offset)` で反映。`direction` は `i % 2` で行ごとに左右交互。
- **スクロール連動**：
  - スクロール量＝「今の `scrollY` − 1フレーム前の位置(`lastY`)」。これを `scrollSpeed` に足す（速くスクロールするほど大きく加速）。
  - `scrollSpeed *= 0.9` を毎フレーム → スクロールを止めると徐々に0へ戻る（加速→減速の"生きてる"感）。
  - `scrollSpeed` は全行で共有する1個の値なので、**減衰は専用ループで1回だけ**（各行のループでやると行数ぶん減衰して即0になる）。
  - `Math.abs(scrollSpeed)` で、上下どちらのスクロールでも加速する（向きは行ごとの `direction` のまま）。

## 実装のポイント（HTML/CSS）

- **マーキーの窓**：`.p-marquee` に `overflow: hidden`（はみ出した文字を隠す）。
- **2セットを横並び**：`.p-marquee__row` を `display: flex` ＋ `white-space: nowrap`。
- **`flex-shrink: 0`（重要）**：文字グループを縮ませない。縮むと `offsetWidth`（ループの戻し基準）が狂う。
- **継ぎ目の隙間**：`.p-marquee__group` の `padding-right`。これは `offsetWidth` に含まれるので、隙間ありのままループは崩れない。
- **スクロール土台**：`.p-marquee` を `position: fixed` で画面に固定し、`.spacer`（高さ200vh）でスクロールの距離を作る（canvas④と同じ）。
- 奇抜カラー（背景ライム × 文字ピンク）＋ Rubik Mono One。

## つまづき＆気づき

- **継ぎ目で文字がくっついた**：グループの末尾に隙間が無く `HOKOHOKO` に。`padding-right`（または末尾に `&nbsp;`）で解決。`offsetWidth` に含まれる余白なのでループは保たれる。
- **戻すときは `= 0` でなく `+= groupWidth`**：端数を残さないとループのたびにカクつく。

## a11y メモ（上司目線）

マーキーは装飾なので `aria-hidden="true"` でスクリーンリーダーから隠すべき（同じ文字を延々読み上げるノイズになる）。常時動く演出なので `prefers-reduced-motion` で停止する配慮も入れた。
