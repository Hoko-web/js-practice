# 検索＆絞り込みフィルター

## 何を作ったか

実績カードの一覧を、キーワード検索とカテゴリボタンでリアルタイムに絞り込む機能。表示件数のカウントと、0件のときの「該当なし」表示つき。検索とカテゴリは組み合わせて効く。

## なぜ・どこで使うか

ポートフォリオの制作実績、ブログ記事一覧、商品一覧などで頻出。静的な一覧に「探す・絞る」体験を足せる。

## 実装のポイント

- 配列の `filter` で「キーワード一致」かつ「カテゴリ一致」の両方を満たすカードだけを抜き出した（`&&` で2条件を結合）。
- `querySelectorAll` の結果（NodeList）は `filter` が使えないので、`[...cards]` で本物の配列に変換してから使った。
- カードの種類は `data-category`、ボタンの条件は `data-filter` に持たせ、`dataset` で読み取って照合した（HTMLに情報を載せてJSで使う実務的な書き方）。
- 「全カードに `is-hidden` を付けて一度全部隠す → 合致したカードだけ外す」で、毎回まっさらにしてから表示（前回の絞り込みの残りを防ぐ）。
- 検索は `input` イベント（打つたびに発火）、カテゴリは `click` イベント。条件が変わるたびに同じ `applyFilter()` を呼ぶ形にまとめた。
- カテゴリボタンは「全ボタンから `is-active` を外す → 押した1つだけ付ける」で常に1つだけ選択中にした（前の選択が押したボタンとは別なので、全部から外すのがポイント）。
