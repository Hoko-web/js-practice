# ドロップダウンナビ（Dropdown Nav）

## 何を作ったか

ヘッダーのグローバルナビで、「事業内容」「会社情報」にホバー／クリックすると子メニューがパネルで開くドロップダウンナビ。外側クリック・Escキーで閉じる。

## なぜ・どこで使うか

コーポレートサイトのグロナビでほぼ必須の部品。下層ページが多いサイト（事業内容・会社情報の下に子ページがぶら下がる構成）で使う。メガメニューの土台にもなる。

## 実装のポイント

- 開閉は `visibility + opacity + translateY` の3点セット。`display: none` は transition でアニメできないので、フワッと出す開閉はこの型にする
- 開くルートは2つ：`:hover`（CSS担当）と `.is-open` クラス（JS担当）。クリック・キーボード操作はJS側が受け持つ
- 「同時に1つだけ開く」は `closeAll()`（全部閉じる）→ 必要なものだけ `add` の型で実現。どれが開いているかを覚える変数が不要になる
- `isOpen` の判定は `closeAll()` より**先に**メモしておく順番が肝。後で見ると常に false になり、2回目クリックで閉じられなくなる
- 外側クリック判定はイベントバブリングを利用。`document` にリスナーを1個置き、`e.target.closest(".js-dropdown")` が null なら外側と判定して全部閉じる

### アクセシビリティ

- 開くトリガーはリンクでなく `<button type="button">`（リンク先のない項目に `<a>` を使わない）
- `aria-expanded` を開閉に合わせてJSで同期、`aria-controls` でパネルのidと紐付け
- キーボード操作対応：Tab移動＋Enterで開閉、Escで閉じる
- `prefers-reduced-motion: reduce` でアニメーションを無効化
